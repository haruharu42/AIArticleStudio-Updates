# Phase 3.5.1 Platform Research — 2026-08-20

目的: note / Tips / Brain の現在の読まれ方・買われ方を再確認し、Web Prompt Engine v2 の掲載先別プロファイルへ反映する。

## note

一次情報として note株式会社が約30万件の有料記事を分析した2026-01-07公表データを優先した。

- 急上昇カテゴリ: テクノロジー・AI活用 +268.6%、SNS・コンテンツ運用 +258.7%、複業・在宅ワーク +179.0%、デザイン・動画制作 +155.4%、育児・教育 +137.3%。
- 売れている記事（分類内売上上位20%）の平均価格は、実用ノウハウ系 1,842円、読み物系 983円。
- 公式説明では、収入アップ/キャリア支援の実用スキルと、育児・教育など日常課題解決ノウハウが伸長。
- note内の観察記事を複数確認すると、有料記事の無料部分は「信頼」「価値の予告」「購入後に得られる内容」が購入判断に強く関係するという共通パターンが見られる。ただし個人記事の売上主張は公式統計ではないため、実装では原則として構成上の示唆としてのみ利用する。

実装反映:
- 無料部分だけでも価値を返す。
- 有料境界前に対象読者・得られるもの・内容を明示。
- noteは読み物としての自然さと本人性を保ちつつ、実用記事では具体的行動へ落とす。
- 最新ジャンル順位や売上数は記事本文へ自動注入しない。

## Tips

Tipsは2025-09-26にランキング機能を公開し、カテゴリ・期間・集計方式・価格帯で、販売額 / 販売数 / レビュースコア / アクセス数を確認できる。

2026年8月時点で確認できるカテゴリ/タグ/ランキングのスナップショットでは、ビジネス、AI、副業、SNS運用、コンテンツ販売、AI自動化などに高価格帯を含むランキング入賞商品が多数見られる。個別商品の販売成果は変動するため、順位そのものはプロンプトへ固定しない。

Tips編集部のコンテンツ販売事例記事では、成功例の共通点として「一人の悩み」「実体験」「継続と信頼」を挙げ、ジャンルは副業・SNS運用・AI・投資・育児・恋愛・占いなど幅広いとしている。

実装反映:
- Tipsは販売ページ+教材の性格を強める。
- 対象読者、悩み、到達点、得られる成果物を早めに明示。
- ロードマップ、手順、テンプレート、チェックリスト、失敗回避を優先。
- 高価格ほど文章量ではなく、時間短縮・再利用性・迷い削減で価値を説明。

## Brain

Brain公式メディアには月次売上ランキングの継続掲載があり、過去のランキング見出しではSNS運用、ブログ用GPTs、仮想通貨などが上位テーマとして紹介されている。

2026年8月時点のBrain人気順検索のスナップショットでは、AI、ビジネス、SNS関連の高価格教材が目立ち、ロードマップ、教科書、運用術、AI活用など「体系化された教材」の形が多い。

実装反映:
- Brainは講座/教材型の構成を優先。
- 販売ページ→ロードマップ→基礎→実践→応用→チェックの流れを基本にする。
- テンプレート、プロンプト、判断フレーム、実例など再利用可能な成果物を重視。
- 高単価想定時は「向かない人」「前提条件」「限界」も書き、誇張だけで販売しない。

## Prompt Engine v2で採用した方針

1. 掲載先別の安定した編集パターンのみコード化する。
2. 日々変わるランキング順位・販売額・販売数はコードへハードコードしない。
3. 実体験・レビュー・実績・売上はユーザー入力または確認済み情報がない限り生成しない。
4. Web版の挿絵ON時は本文構成段階で最適位置を選び、`[挿絵N｜差し込み位置｜役割]` の固定マーカーを出す。
5. 画像生成用の長いプロンプトは本文と分離し、後段のAPI / Web / ローカルGPU画像生成で作る。
