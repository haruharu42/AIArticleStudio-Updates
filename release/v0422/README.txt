AI Article Studio v0.4.2.2

This update improves the Phase 3.6 image workflow.

Changes:
- Moves image controls out of the upper article settings area and into the Web article preview flow.
- Links image prompts to the imported/formatted Web article text, title and headings.
- If an older article has no illustration markers, illustration positions can be proposed from headings.
- Adds Anime, Manga, Pop, Luxury, Catchy Thumbnail, Natural, Minimal and Infographic style presets.
- Shows specific preparation errors when image prompts cannot yet be created.

Direct API image generation and local GPU model execution remain disabled in this version.
