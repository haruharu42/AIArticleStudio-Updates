AI Article Studio v0.4.2.6
================================

This update corrects the guided article-creation layout introduced in v0.4.2.5.

- Never opens the Web AI workflow in a separate application window.
- Keeps every article-creation step inside the main Article Creator screen.
- Starts with a generation-method selection screen.
- Shows the image plan immediately after generation method.
- Displays each remaining setup section one at a time.
- Keeps Back and Next navigation in a consistent position.
- Embeds title generation, title selection, article paste, formatting, history, and output in the same main screen.
- Adds a clear "Back to settings" action without losing the current local draft.
- Preserves the ten-item local recent-work history from v0.4.2.5.

The updater verifies v0.4.2.5 before patching and validates that the Web AI workflow no longer uses a Toplevel window.
